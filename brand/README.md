# Папка бренда

Скопировать логотип: откройте **`svg/mark.svg`** и сохраните файл.

Аватар бота в Telegram: **`telegram/avatar-640.png`**.

Полные правила: [BRAND.md](BRAND.md).

```
brand/
  svg/           ← векторы, это источник
  telegram/      ← PNG для BotFather
  logo-maker/    ← размеры и favicon из нашего SVG
  logo-maker-kit/← авто-кить logo_maker из имени (не путать со знаком)
```
