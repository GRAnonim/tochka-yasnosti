# Точка ясности

Telegram Mini App (тестовая версия) для саморефлексии и спокойных решений:  
цели → ситуация → фильтр → вопросы → мягкое резюме → решение → обратная связь → статистика.

**Это не терапия и не диагностика.** Рядом с психологом или для личной ясности.

## Фазы продукта

| Фаза | Что делаем | Статус |
|------|------------|--------|
| **1. Тест A→Я** | Цикл решения + пакеты **1–4** + спокойный UI + **колесо баланса с кругом, датой и скачиванием PNG** + журнал + follow-up + статистика + «мой специалист». Без LLM. Данные в `localStorage`. | **сейчас** |
| **2. Полная версия** | Больше упражнений (дневник настроения, благодарность, ABC), напоминания, полировка UX, хостинг Mini App + бот. | далее |
| **3. Психологи** | Тихий блок «мой специалист» уже есть. Потом отдельная доска/каталог — не внутри потока рефлексии. | после фазы 2 |
| **4. Монетизация** | Freemium / подписка / партнёрства — только после доказанного удержания. | в конце |

## Экономия токенов (Cursor / Gemini)

Для фазы 1 **модель не нужна**: вопросы и резюме — правила и шаблоны.  
Так мы не жжём лимиты Cursor на каждый ответ пользователя.

**Google Gemini** имеет смысл позже — на *рутинных* кусках runtime (перефраз резюме, классификация фильтра), а не на всей разработке в Cursor:

- разработка и архитектура — в Cursor точечно;
- дешёвые/рутинные вызовы в продукте — Gemini / другой API по вашей подписке;
- ещё экономнее: оставить шаблоны и подключать модель только там, где шаблон реально слабее.

Другие варианты с низким расходом Cursor:

- этот репозиторий на **GitHub** + деплой (Vercel/Fly) — код хранится бесплатно, Cursor нужен только когда правите;
- открытые шаблоны Telegram Mini Apps как референс (не обязательно форкать);
- локальный прогон `npm run dev` без агента для мелких правок вручную.

## Запуск локально

```bash
npm install
npm run dev
```

Откройте [http://127.0.0.1:3000](http://127.0.0.1:3000).  
В браузере работает без Telegram; внутри Telegram подхватится `telegram-web-app.js`.

## Telegram Mini App

1. Создайте бота у [@BotFather](https://t.me/BotFather) (`/newbot`).
2. Сохраните токен бота **только у себя** (в `.env` локально, не в git).
3. `/setmenubutton` или Bot Settings → Menu Button → Web App URL → ваш **HTTPS** адрес.
4. Либо `/newapp` → привяжите Web App к боту с тем же HTTPS URL.
5. Откройте бота в Telegram → кнопка меню / команда → Mini App.

Фаза 1 работает без backend: данные только в `localStorage` устройства.

**Важно:** временный Cloudflare-туннель для теста работает только пока крутится Cursor.  
Чтобы мини-приложение жило постоянно (как Time Filter) — нужен хостинг, см. ниже.

## Постоянный хостинг — как Time Filter (GitHub Pages)

У [Time Filter](https://granonim.github.io/timefilter-mini/) мини-приложение — обычные файлы сайта на **GitHub Pages**.  
Их раздаёт GitHub, а не ноутбук. Кнопка в боте просто открывает эту ссылку.  
Данные остаются на телефоне (`localStorage` / Telegram CloudStorage).  
На ноутбуке крутится только бот (`/start`, админка) — без ноутбука чат молчит, а Mini App открывается.

«Точка ясности» настроена так же: `next build` собирает **статику** в папку `out/`, GitHub Actions выкладывает её на Pages.

### Что сделать один раз

1. Создайте репозиторий **`tochka-yasnosti`** у пользователя `GRAnonim`  
   (имя важно: от него зависит адрес `/tochka-yasnosti/`).
2. Залейте этот код в `main` (можно сделать репозиторий **private**, но для GitHub Pages на бесплатном плане обычно нужен **public** — как у Time Filter; либо GitHub Pro).
3. В репозитории: **Settings → Pages → Source: GitHub Actions**.
4. После пуша Actions соберёт сайт. Адрес будет:  
   **https://granonim.github.io/tochka-yasnosti/**
5. В боте «Точка ясности» укажите этот URL как Web App / Menu Button.

Локальная проверка сборки Pages:

```bash
npm run build:pages
```

Откроется содержимое в `out/`.

Бот (`/start`) по-прежнему может жить на ноутбуке/в Cursor — как у Time Filter.

## Админка в боте

Пока крутится `npm run bot`, напишите боту **`/admin`**. Первый, кто это сделает, становится администратором. Дальше в чате панель:

- сколько человек зашло в бот;
- сколько открывали Mini App;
- кто активен за сегодня / 7 дней / 30 дней;
- какие практики начинают (только счётчики, без текстов записей).

Цифры лежат локально в `data/bot-stats.json` (файл не коммитится).

Закрепить себя можно в `.env.local`:

```
ADMIN_TELEGRAM_IDS=123456789
```

Открытия Mini App с GitHub Pages доходят в админку, только если бот доступен по HTTPS (туннель или маленький хостинг). Тогда укажите адрес ingest:

- в `public/stats-ingest.json` поле `url`, или
- секрет GitHub Actions `STATS_INGEST_URL` (подставится при сборке Pages).

Пока бот только на ноутбуке, надёжно считаются заходы в чат (`/start` и сообщения).
